No generative AI was used in the making of this project. 

Before starting the program it is important to have matplotlib installed to properly run this program. When the program runs it will ask you for the path to the data sets that you would like to use for the plotting done in task 3. After that it will ask you to which mode you would like to choose, scatter plot mode (which will automatically populate the graphs within a set range) and user input mode (which will ask for the data from the user to plot onto the graphs).
